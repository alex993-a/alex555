# HBR Token：本地测试原型

这是一个**仅供本地 EVM 测试**的 HBR ERC-20 原型。它不用于主网部署、募集资金、面向公众发行或任何真实交易，也不代表、暗示或承诺可以上架 OKX。

## 设计边界

- 名称：`HBR Token (Local Prototype)`；符号：`HBR`；`decimals`：`18`
- 总量固定为 `1,000,000,000 HBR`，部署时全部分配给构造函数指定的初始持有人
- 合约没有 `mint`、管理员、升级、税费、黑名单或隐藏转账逻辑；部署后供应量不可增加
- `HBR/USDT` 仅可作为界面或测试中的计价示例：HBR 不是稳定币，不承诺 1:1 兑付
- 不要使用真实私钥、真实 RPC、交易所凭证或真实资金

## 本地运行

需要 Node.js 18+。安装依赖并运行 Hardhat 本地测试：

```bash
npm install
npm test
```

只编译合约：

```bash
npm run compile
```

测试网络由 Hardhat 在本地内存中提供；项目没有部署脚本，也不包含主网 RPC 或私钥配置。
